# Stash App

Stash is a personal resource library web application. It allows you to save links from anywhere, organize them into collections, and find them in seconds.

## Features

- **Auth Screens**: Elegant Login & Sign-up pages.
- **Library View**: A grid of all saved resources.
- **Collections**: Group related resources together (e.g., CSC 301, Coding Resources).
- **Unsorted View**: Easily find and categorize newly saved resources.
- **Resource Management**: Rename, move, and delete resources.

## Development

This project contains the core MVP application in `StashApp.jsx` built with React and Lucide React icons.
